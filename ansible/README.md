# Ansible

Configures nodes created by Terraform. The inventory
(`inventories/lab/hosts.yml`) is generated by `terraform apply`. It defines the
`controllers`, `computes` and `ceph` groups and gives every host an
`aura_addresses` map of interface name to IP.

## Playbooks

| Playbook        | Hosts            | Does |
|-----------------|------------------|------|
| `bootstrap.yml` | all              | Waits for cloud-init, then applies the `common` role |
| `ceph.yml`      | ceph             | Deploys Ceph with cephadm; creates OpenStack pools and client keys |
| `openstack.yml` | controllers[0]   | Installs Kolla-Ansible on the deployment host, renders config, deploys OpenStack |
| `site.yml`      | -                | Runs all three in order |

`openstack.yml` uses tags so configuration can be rendered and reviewed before
a deploy:

```bash
ansible-playbook playbooks/openstack.yml --tags kolla-install,kolla-config
ansible-playbook playbooks/openstack.yml --tags kolla-deploy
```

## Roles

| Role     | Key variables (see `defaults/main.yml`) |
|----------|------------------------------------------|
| `common` | `common_packages`, `common_ntp_servers`, `common_sysctl`, `common_sshd_settings` |
| `ceph`   | `ceph_container_image`, `ceph_openstack_pools`, `ceph_openstack_clients`, `ceph_cluster_network` |
| `kolla`  | `kolla_openstack_release`, `kolla_internal_vip_address`, `kolla_actions`, `kolla_ceph_keyrings` |

Environment-specific overrides, such as release pins and NTP servers, go in
`inventories/<env>/group_vars/all.yml`. Don't edit role defaults for that.

## Secrets

Nothing secret is stored in this repository. Kolla's `passwords.yml` and
deployment SSH key are generated on the deployment host under `/etc/kolla`.
Ceph client keys are read from the Ceph admin node at deploy time and written
only to `/etc/kolla/config` (mode `0600`).
